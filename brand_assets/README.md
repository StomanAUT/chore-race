# Chore Race brand assets

- `icon.png`: 512 x 512 px transparent PNG
- `icon@2x.png`: 1024 x 1024 px transparent PNG

The mark combines a home, a completed chore, and a subtle racing flag. Navy,
cyan, and coral keep it readable in both light and dark Home Assistant themes.

The source artwork was generated with OpenAI ImageGen and exported with
`scripts/export_brand_assets.py`.
